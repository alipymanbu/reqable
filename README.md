## 主要功能一览

**流量抓包与分析**
支持 HTTP/1.x、HTTP/2、HTTP/3(QUIC) 全协议，以及 HTTPS、WebSocket、Socks 代理方式。抓到的流量可以按应用、域名、类型多维度筛选，找起来不费劲。

**多端协同调试**
手机端扫二维码，不用手动配 Wi-Fi 代理，流量直接转发到电脑端。在电脑上就能操作手机的网络请求，断点、重写、回放都行。Android 端还有增强模式，可以抓 Flutter App 这类不走系统代理的应用。

**自由重写与断点**
支持规则重写、实时断点拦截、Python 脚本三种方式，测试场景想怎么定制就怎么定制。

**内置对比工具**
请求和响应的差异可视化展示，方便排查问题。

**API 测试**
支持创建 API 集合、环境变量、多 Tab 并发测试，HTTP/2 和 HTTP/3 都支持，能从 Postman、ApiPost、ApiFox 导入数据，迁移成本低。

**内置开发小工具**
Base64 编解码、URL 编解码、MD5 计算、JSON/XML 格式化、二维码生成……常用的都塞进来了，真正一站式。
